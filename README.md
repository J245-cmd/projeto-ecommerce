# Projeto Ecommerce

Aplicação legado migrada de arquivos `.zip` para versionamento com Git.

## Sobre

Este repositório contém a estrutura inicial de uma loja online, criada como
exercício prático de versionamento com Git CLI.

## Estrutura

- `index.html` — estrutura inicial da página
- `styles.css` — estilização do cabeçalho
- `README.md` — este arquivo
